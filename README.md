# দিনলিপি (Dinlipi)

**প্রতিদিনের ছোট ছোট তথ্য, এক জায়গায়।**

*An offline-first personal health, study and daily life tracker with event-based logs, Bengali UI and JSON backup. No server, no account.*

দিনলিপি একটি অফলাইন-ফার্স্ট ব্যক্তিগত ট্র্যাকার — ঘুম, খাবার ও পানি, ওজন, পড়াশোনা, কাজ, ব্যায়াম, স্বাস্থ্য জার্নাল, অভ্যাস, রুটিন ও লক্ষ্য। সব তথ্য শুধু আপনার নিজের ডিভাইসে থাকে। কোনো সার্ভার নেই, কোনো অ্যাকাউন্ট নেই, ইন্টারনেট ছাড়াও অ্যাপ চলে।

- অ্যাপের ভাষা: বাংলা
- ডেটা: ব্রাউজারের `localStorage`
- ব্যাকআপ: JSON ফাইল (আপনার নিজের নিয়ন্ত্রণে)
- ইন্টারফেস: মোবাইল-ফার্স্ট, ডার্ক ও লাইট থিম

এছাড়া:

- **একাধিক এন্ট্রি:** একই দিনে একাধিক খাবার, সেশন বা ব্যায়াম যোগ করা যায়।
- **সম্পাদনা ও মুছে ফেলা:** প্রতিটি এন্ট্রি পরে বদলানো বা মুছে ফেলা যায়।
- **কুইক অ্যাড:** যেকোনো পেজ থেকে দ্রুত নতুন এন্ট্রি।
- **শুধু রেকর্ড থেকে হিসাব:** সব সংখ্যা আপনার দেওয়া তথ্য থেকেই আসে; কোনো অনুমান বা বানানো ডেটা নেই।
- **নিজের রিমাইন্ডার বার্তা:** চাইলে নিজের লেখা মোটিভেশনাল বার্তা যোগ করা যায়।
- **আইকন:** সব আইকন `lucide-react` থেকে, কোনো ইমোজি নেই।

## ডেটা মডেল

ডেটা "দিনের একটি ফর্ম" নয় — বরং **ইভেন্টের তালিকা**। প্রতিটি রেকর্ডের নিজস্ব `id`, `date` ও সময় থাকে, তাই:

- একই দিনে যতবার দরকার ততবার এন্ট্রি করা যায়
- প্রতিটি এন্ট্রি আলাদা করে সম্পাদনা বা মুছে ফেলা যায়
- রিপোর্ট ও চার্ট রেকর্ড থেকেই তৈরি হয়

মূল সংগ্রহগুলো: `sleep`, `meals`, `water`, `study`, `work`, `exercise`, `health`, `weights`, `subjects`, `habits`, `chapters`, `routine`, `goals`। এর সঙ্গে আছে `habitLogs`, `routineLogs`, `reflections` এবং `profile`, `settings`, `reminders`।

সবকিছু একটি Zustand স্টোরে থাকে এবং `localStorage`-এ সংরক্ষিত হয়। মূল কী: `life-tracker-v2`।

## চালানো

প্রয়োজন: **Node.js 18.17 বা তার পরে**।

```bash
npm install
npm run dev
```

ব্রাউজারে `http://localhost:3000` খুলুন।

প্রোডাকশন বিল্ড (স্ট্যাটিক ফাইল তৈরি হবে `out/` ফোল্ডারে):

```bash
npm run build
```

বিল্ড হওয়া সাইট লোকালি দেখতে:

```bash
npx serve out
```

বা:

```bash
python -m http.server 4173 --directory out
```

> নোট: `out/` ফোল্ডার সরাসরি ফাইল থেকে (`file://`) খুললে Service Worker ও PWA ইনস্টল কাজ করবে না — HTTP সার্ভার লাগবে।

## ডিপ্লয়

### Vercel (সুপারিশকৃত)

এই প্রজেক্টটি Vercel-এ কোনো অতিরিক্ত কনফিগ ছাড়াই চলে:

1. [vercel.com/new](https://vercel.com/new) থেকে GitHub রিপো `dinlipi` ইমপোর্ট করুন
2. Framework: **Next.js** (স্বয়ংক্রিয়ভাবে ধরা পড়বে)
3. Build command: `npm run build` — ডিফল্টই ঠিক আছে
4. Deploy চাপুন

`output: "export"` থাকায় Vercel স্ট্যাটিক ফাইল হিসেবে সাইটটি পরিবেশন করবে। প্রতিটি পুশে স্বয়ংক্রিয়ভাবে নতুন ডিপ্লয় হবে। Vercel ডোমেইন HTTPS-সহ আসে, তাই Service Worker ও নোটিফিকেশন কাজ করবে। কাস্টম ডোমেইন যোগ করলেও `basePath` লাগবে না।

### অন্য হোস্ট

`out/` ফোল্ডার যেকোনো স্ট্যাটিক হোস্টে দেওয়া যায়:

- **Netlify** — build command `npm run build`, publish directory `out`
- **Cloudflare Pages / যেকোনো স্ট্যাটিক সার্ভার** — `out/` আপলোড করুন

সাইট যদি ডোমেইনের রুটে (`https://example.com/`) থাকে, তবে এখনকার কনফিগারেশনেই চলবে। GitHub Pages-এর প্রজেক্ট সাইট (`https://user.github.io/dinlipi/`) হিসেবে চালাতে চাইলে `basePath` যোগ করতে হবে এবং `manifest.json`, `sw.js` ও আইকনের পাথ সেই অনুযায়ী বদলাতে হবে — অথবা কাস্টম ডোমেইন ব্যবহার করুন।

## PWA ও অফলাইন

- `public/manifest.json` — অ্যাপের নাম, আইকন, থিম ও স্ট্যান্ডঅ্যালোন ডিসপ্লে
- `public/sw.js` — নেভিগেশনে network-first, বাকি ফাইলে cache-first; পুরোনো ক্যাশ স্বয়ংক্রিয়ভাবে মুছে যায়
- অ্যাপ ইনস্টল করার পর হোম স্ক্রিন থেকে আলাদা অ্যাপের মতো খোলা যায়
- একবার লোড হওয়ার পর ইন্টারনেট ছাড়াও আগের পেজগুলো খোলা যায়
- আপডেট পেতে অ্যাপ বন্ধ করে আবার খুলুন

Android-এ Chrome থেকে **Add to Home screen** দিলে সবচেয়ে ভালো অভিজ্ঞতা পাওয়া যায়।

## নোটিফিকেশন রিমাইন্ডার

সেটিংস → **নোটিফিকেশন রিমাইন্ডার** থেকে চালু করা যায়। কোনো push সার্ভার বা FCM নেই — সব কিছু ডিভাইসেই হয়।

- সময়সীমা: প্রতি ১, ২, ৩, ৪ বা ৬ ঘণ্টা (ডিফল্ট ৩)
- বিশ্রামের সময় নির্ধারণ করা যায় (ডিফল্ট রাত ১০টা – সকাল ৭টা)
- নিজের মোটিভেশনাল বার্তা যোগ ও মুছে ফেলা যায় (সর্বোচ্চ ২০টি) — ডিফল্ট বার্তার সঙ্গে এগুলোও এলোমেলোভাবে বাছাই হয়
- অ্যাপ খোলা থাকলে নির্ধারিত সময়ে লোকাল নোটিফিকেশন আসে
- অ্যাপ বন্ধ থাকার পর আবার খুললে একটি মিস হওয়া রিমাইন্ডার দেখানো হয়
- Android-এ ইনস্টল করা PWA-তে Periodic Background Sync-ও চেষ্টা করা হয়
- "পরীক্ষা" বাটনে চাপলে সঙ্গে সঙ্গে একটি নোটিফিকেশন দেখা যায়

### সীমাবদ্ধতা (সৎভাবে)

- অ্যাপ সম্পূর্ণ বন্ধ থাকলে **ঠিক প্রতি ৩ ঘণ্টায়** নোটিফিকেশন আসার নিশ্চয়তা নেই। কখন ব্যাকগ্রাউন্ড কাজ চলবে তা ব্রাউজারই ঠিক করে।
- ফোনের ব্যাটারি অপ্টিমাইজেশন থাকলে ব্যাকগ্রাউন্ড রিমাইন্ডার বন্ধ থাকতে পারে। Chrome বা অ্যাপের জন্য ব্যাটারি সেটিং "Unrestricted" করলে ভালো কাজ করে।
- iPhone/iOS-এ ব্যাকগ্রাউন্ড রিমাইন্ডার সীমিত।
- অনুমতি না দিলে কোনো নোটিফিকেশন আসবে না।
- হুবহু সময়ে নিশ্চিত রিমাইন্ডার দরকার হলে PWA যথেষ্ট নয় — native wrapper বা push সার্ভার লাগবে।

## ব্যাকআপ ও প্রাইভেসি

- সেটিংস → ব্যাকআপ থেকে সম্পূর্ণ ডেটা **JSON** ফাইলে রপ্তানি করা যায়
- একই ফাইল অন্য ডিভাইসে আমদানি করা যায়
- ব্যাকআপে প্রোফাইল, সেটিংস, রিমাইন্ডার কনফিগ ও সব এন্ট্রি থাকে
- Excel সমর্থন নেই — শুধু JSON, যাতে ডেটা অক্ষত ও যাচাইযোগ্য থাকে

**গোপনীয়তা:** কোনো অ্যাকাউন্ট নেই, কোনো ট্র্যাকিং বা অ্যানালিটিক্স নেই, কোনো ডেটা কোথাও পাঠানো হয় না। ব্রাউজারের ডেটা মুছে ফেললে (`Clear site data`) রেকর্ডও মুছে যাবে — তাই নিয়মিত JSON ব্যাকআপ রাখুন।
